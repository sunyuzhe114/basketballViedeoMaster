# 篮球剪辑大师

固定机位篮球视频的本地 Windows 剪辑软件。视频和球员照片在本机处理。

## 启动

双击上一级目录的 **启动篮球剪辑大师.bat**，或在上一级目录运行 `python -m basketball_master`。本机若已有 **篮球剪辑大师.exe** 启动器，也可双击启动。

首次使用需准备 Python、PyQt5、OpenCV、FFmpeg 和 YOLO11s 模型，具体步骤见下文。源码仓库不包含编译后的 EXE。EXE 仅是启动入口，运行时需要旁边的 `basketball_master` 文件夹及本机 Python；它不是可单独复制到其他电脑的独立安装包。

换电脑时需要 Python 3.10 或更高版本、FFmpeg / FFprobe，并运行上一级目录的 `setup.bat`。GPU 非必需，CPU 也可处理，速度会较慢。

## 全部进球集锦

1. 导入视频。每个视频有独立的篮筐标定和项目记录。
2. 跳转到篮筐清楚的画面，点击“框选篮筐”。“区域触发（宽松）”可框选篮板和篮筐附近需要监测的区域；“标准 / 严格”模式需紧贴篮圈与篮网，不包含整块篮板。可以标记多个区域。

   已有区域可直接调整：拖动四边或四角改变大小，按住框内移动整个框。选中的框显示 8 个调整手柄；开始拖动会暂停预览，松开鼠标自动保存，按 Esc 取消本次调整。边框不会超出视频画面。分析或导出期间暂时锁定区域，调整后历史候选保持不变，后续检测使用新区域。
3. 选择“全部进球集锦”，设置分析起止时间，点击“开始分析”。也可以先“从当前时间试跑 1 分钟”。
4. 点击候选列表中的一行回放，将状态改为“确认进球”或“未进 / 误检”。漏掉的球可在相应时间“补记进球”。
5. 勾选片段，调整进球前后时长和分辨率，点击“导出集锦”。在筛选窗口勾选进球状态和球员归属，确认片段数量、合并后时长及待复核数量，再选择保存目录。

## 指定球员进球集锦

1. 导入球员全身照片，或者拖动视频到球员清楚的时间，再“从画面框选球员”。支持多个正面、背面样本，不要求第一帧有人。
2. 选择“指定球员进球集锦”，开始分析。程序先找候选进球，再识别出手人。已有候选时，可直接点击“识别进球球员”。
3. 查看“疑似目标”和“待确定”片段，将归属改为“确认目标”或“其他球员”。人工指定的归属不会被后续识别覆盖。
4. 此模式默认导出勾选的“确认目标 / 疑似目标”。导出窗口可以明确改选其他归属；最后以窗口中选择的状态为准。主界面的“仅目标 / 疑似目标”只筛选列表显示，不限制导出窗口中的候选范围。

## 播放快捷键

- 空格：播放 / 暂停。
- 左方向键：默认后退 3 秒；右方向键：默认前进 1 秒。
- 右上角“设置”可分别调整后退、前进的秒数，范围 0.1-60 秒，默认分别为 3 秒、1 秒。已有手动设置会保留，快捷键与画面下方的两个跳转按钮同步使用设置值。
- “设置 → 界面语言”支持中文和 English，默认中文。选择后可预览设置窗口的语言，点击保存后主界面立即切换并记住选择；取消不影响原界面。主界面、右键菜单、导出筛选、状态提示和检测说明跟随语言；原视频文件名、项目记录和导出清单不做翻译，系统原生文件选择器的按钮跟随 Windows。
- “设置 → 导出设置”统一配置进球前、进球后的预留秒数（各 1-60 秒，默认 6 秒 / 4 秒），以及分辨率（1080p、原始分辨率、720p）。保存后对所有视频生效，重启后保留；切换视频不会恢复旧项目中的预留秒数。手动指定的单个片段起止时间保持不变。右侧不再显示这三项设置，仍保留导出按钮和片段统计。
- 跳转保留当前播放或暂停状态，到视频末尾会暂停。
- 编辑时间输入框、操作下拉框或弹出对话框时，保留控件本身的按键行为。点击视频画面或候选列表后可继续使用播放快捷键。
- 设置单独保存在 `data/preferences.json`，重启后保留，清空视频列表不会重置；设置窗口可恢复默认值。
- 选中一条候选后，跳转按钮旁的“设为片段”可将时间框里的值填为当前片段起点，终点设为 10 秒后并自动保存。手动输入时间后不必先跳转；接近视频结尾时终点自动截到末尾。此操作会暂停播放，但不改变进球时间、状态、球员归属或导出勾选。

## 导出筛选

- 每次点击“导出集锦”都会显示筛选窗口。进球状态可多选“确认进球 / 待复核 / 未进误检”，球员归属可多选“确认目标 / 疑似目标 / 待确定 / 其他球员”。
- 片段必须同时符合所选的进球状态和球员归属。同一组内的多个状态取并集。
- “已勾选片段”只从表格勾选的条目中筛选；“全部候选片段”也包含未勾选的条目。未进球通常已取消勾选，需要导出时可选全部候选范围。
- 默认不导出“未进 / 误检”。选择非默认筛选条件时，输出名称为“筛选集锦”，具体条件会记录在 `events.json` 中。
- 窗口实时显示匹配数量、合并后的时长和待复核状态数量。没有匹配片段时不能继续；取消窗口或目录选择不会开始导出。

## 保存与导出

- 项目自动保存到 `data/projects/`。关闭软件后可继续复核，无须重新扫描。
- 左侧视频素材列表支持右键“移除此视频”和“清空视频列表”。只移除列表条目，不删除原视频或已保存的分析记录；重新导入后可继续复核。
- 候选进球上方的“取消全选”只取消导出勾选。右侧带垃圾桶图标和文字的“清空进球列表”按钮会在确认后删除当前视频的全部候选和人工标记，包括筛选隐藏的记录；保留篮筐标定、球员样本、原视频及已导出的文件。
- 候选进球行支持右键“删除此候选”，确认后仅删除右键对应的一条记录并自动保存。若删除的是当前回放片段，会同时暂停并清空片段详情；原视频和导出文件不受影响。重新分析同一段视频可能再次检测到已删除的候选。
- 候选列表的“进球状态”和“球员归属”可直接用下拉框修改，选完自动保存并同步右侧详情、筛选和导出统计，不改变片段时间。选择“已排除”会取消该片段的导出勾选；手动修改球员归属后，自动识别不会覆盖这次确认。分析或导出期间暂时锁定列表编辑。
- 候选进球行还支持右键“设为分析起始时间”和“设为分析终止时间”，将右击记录的进球时间填入右侧分析范围，精度为 0.1 秒；不会改动片段时间或另一端时间，也不会自动开始分析。可依次设置两端，再点击“开始分析”；结束时间必须晚于开始时间。
- 导出目录由用户选择。每次生成独立子文件夹，包含合并 MP4、分段 MP4、JSON 和 CSV 时间记录。
- 相互重叠的片段自动合并，避免重复播放同一段画面。导出按源视频时间排序。
- 从原视频重新编码以精确截取，支持 1080p、720p 和原始分辨率。保留现场声音；可用时自动使用 NVIDIA 编码，无法使用时回退到 CPU。
- 选中候选后可跳到识别的出手时刻，画面上的黄色框标出候选出手人。键盘上下键也可切换列表中的片段。
- 窗口内画面预览是静音的；导出的 MP4 带原声，可用系统播放器检查。
- 任务可停止。已经发现的候选会保留；取消导出会清理本次未完成的输出。

## 识别范围

右侧“检测方式”提供三种模式：

- **区域触发（宽松）**：疑似篮球接触或进入框选区域即可列为待复核候选，不要求从上向下或从下向上的完整轨迹，默认勾选导出。结合相邻帧差、背景差分、最小尺寸和紧凑的圆形轮廓，扣除整体曝光变化，并检查是否像实体遮住背景，减少小块反光、篮网晃动和背景残影造成的误触发。持续停留和短时间重复进入不会每帧重复记球。适合希望少漏掉出手、篮板碰撞等片段的情况，但低对比度、遮挡或形似篮球的反光仍可能漏检或误检，需要人工复核。
- **标准 / 严格**：检查完整的篮圈、篮网穿越轨迹。向下规则要求球从篮圈上方穿到篮网下方；向上规则检查球从篮网下方穿过篮圈。“严格”还要求更完整的轨迹证据。

新项目默认使用区域触发，已有项目保留原检测方式。要复查当前视频第 8–11 分钟，可切换到“区域触发（宽松）”，将分析范围设为 480–660 秒后重新分析。已有复核记录不会被清空。设置中的“同时检测从下向上的轨迹”只影响标准/严格模式；区域触发始终不限制方向。表格的“证据分”是启发式证据分，不是经过统计校准的准确率。

预览播放时会即时检查框选区域。触发后，对应边框红蓝交替，离开后约 1.2 秒恢复绿色；暂停时停留在当前视频时刻的颜色。回放、跳转到已分析的区域候选时也会显示提示；未分析片段仅跳到单帧不能判断运动，需要继续播放。跳转、切换视频或修改框选区域会重建背景，连续播放开始约 0.5 秒后启用运动判断。闪烁只绘制在软件预览层，不改变原视频、候选状态或导出画面。

检测规则升级后，新分析和即时预览使用新规则，但已保存的历史候选及其回放提示不会自动删除。已确认的旧误检可右键“删除此候选”或标为“未进 / 误检”；重新分析不会自动清理它们。判断误触发时请看表格的进球时间，片段起点包含“进球前”的预留时长，并不代表该时刻检测到了球。

方向指画面坐标中的轨迹，不能单凭方向或进入区域认定有效得分。所有检测结果都先列为“待复核”，其中向上候选默认不勾选导出，需要回放确认后再勾选。“触发方式”列显示从上向下、从下向上或区域触发，JSON/CSV 导出记录也包含 `direction`。不同触发方式独立去重，避免相互覆盖；切换模式重扫可能保留同一次出手的多种候选，导出时重叠片段仍会合并。

修改检测设置后，需要重新分析相应时间范围才能补出向上候选，无需先清空已有记录。旧记录没有方向信息时显示“未标注”，重扫匹配的向下记录后可补充方向；已有人工进球状态和球员归属不会被覆盖。

球员识别使用 YOLO11s、ByteTrack、出手前的球与球员位置关联，以及上衣、短裤、腿部的衣着特征。它不会读取球衣号码，也不进行人脸识别。同款球衣、遮挡、球过小、离开画面、镜头移动等情况可能误判或漏检，因此提供逐球回放、人工归属和补记。当前版本没有声称能自动、无遗漏地识别整场所有进球。

参考实现接口：[Ultralytics 多目标跟踪文档](https://docs.ultralytics.com/modes/track/)。YOLO / Ultralytics、PyQt5 和 FFmpeg 的许可分别由其上游项目提供。

## 命令行与验证

在上一级目录运行：

```powershell
python -m basketball_master
python -m pytest basketball_master/tests -q
python -m basketball_master.cli scan DJI_20260826193250_0017_D.MP4 --start 0 --end 300
python -m basketball_master.cli players DJI_20260826193250_0017_D.MP4
```

命令行分析与桌面窗口不要同时编辑同一个项目。诊断日志位于 `data/errors.log`。测试截图和真实视频样片位于上一级目录的 `work/` 和 `篮球剪辑大师测试导出/`。
